# MediaGroots replica

This is a captured, working copy of the supplied public Framer website, checked against the 12 October 2026 screen recording. It preserves the original markup, CSS, fonts, images, compiled React/Framer components, animation settings, and project CMS records. It is not the editable native Framer project.

## Preview locally

Run `npm start` in this directory, then open `http://127.0.0.1:4173`. No dependency installation or build is needed. `npm run check` validates the captured files.

## Included

- Home page and all four project detail pages.
- Original responsive layouts, scroll reveals, navigation scrolling, page wipe transitions, hover effects, and animated illustrations.
- Service accordions, process controls, work links, statistics and testimonial slideshows, FAQs, and the original contact form controls.
- Original text, including placeholders, social destinations, pricing link behavior, and contact details.

The “Made in Framer” badge is hidden on every page, as requested. Recapture reapplies this customization automatically.

The contact form retains the original Framer configuration. Message delivery is not verified; the supplied recording shows “Something went wrong.” No form submissions were made during validation. The informational AI service descriptions and case studies are preserved; the website itself does not supply separate working AI applications for those services.

`capture-manifest.json` records the original page and asset sources. The files in `scripts/` support recapture, local serving, and asset address configuration. Compiled Framer runtime warnings also occur on the original site; its component behavior was retained.
